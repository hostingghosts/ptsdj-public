# First hardware test (nothing here has run on a Tracker yet)

Image: `build/PolyendTracPTSDJv<ver>.ptf` (24-char name, `make CROSS=... ` checks it). Way back: reflash the stock `.ptf`.

Before flashing (LEARNINGS.md, "Recovery before testing"):
1. SD card: `/Firmware` holds only the stock image (`PolyendTracker_CE_1.0.0.ptf`) and this test image; everything else elsewhere (the rear reset button installs a random `.ptf`).
2. Put the stock image's name in `/Firmware/ot_restore.txt`: the app checks it right after the SD mounts, installs that image on the next boot and renames the file `.done`.
3. Copy your own `GB/LSDJ.GB` to the card (kits and the synth need it) and a demo to `GB/AUTOLOAD.LSDSNG` (optional `GB/AUTOLOAD_B.LSDSNG`).

Checks, in order (stop at the first failure and report what the screen showed):
1. Boots to the green LSDJ screen; keys move the cursor; the jog wheel edits.
2. Play: both consoles start and stop together; no clicks or dropouts (A alone, then A+B).
3. Synth screen (Fx1 (Synth page)): change SIGNAL; the frames rebuild. The bottom line shows `REBUILD nnnK CYC` (device cycles at 180 MHz: 18000K = 100 ms). Report that number; under ~30000K (170 ms) feels instant.
4. Power-on: the block letters PTSDJ drop to the middle of the grey-lens display, then the two-note chime.
5. Project: NAME the song (Insert on NAME), SAVE SONG, power off, LOAD SONG; EXPORT WAV (progress bar) and check `GB/Export/<name>.wav`; EXPORT LSDJ (turn the jog wheel to pick A, B or A+B) writes `.lsdsng` and `.sav`.
6. Pads: sound only, never the song; on the Instr page a pad plays that instrument (wave and kit instruments too); Rec on the Phrase page arms, jog picks the instrument, Rec + Play loops the phrase over the song and records.
7. SYNC: set A to MASTER and B to SLAVE (Project); Play starts both; changing A's tempo changes B's; SYNC OFF on both, then Play on one console: the other must be silent (no stuck note). Master key: side by side; F1/F8 pick, F2/F7 + jog level, F3-F6 mute, Shift + F3-F6 solo.
8. Edit helpers: Shift + Insert + arrows select, Copy, Shift + Copy paste; Help key shows the help pages; CLEAN SONG DATA / CLEAN INSTR DATA ask for a second Insert.
9. Instrument library (Sample loader): save an instrument, load it into another slot.
10. New in 0.3.0: Delete alone clears a cell (Song, Chain, Phrase, Table); select several with Shift + Insert + arrows, then Delete clears them or the jog wheel changes them all.
11. Instr page: arrow Up onto the number, Left/Right or the jog wheel scroll instruments, pads play the one shown. Name keyboard: Delete = NO, `<` erases; everything is inside the border.
12. Hold F8 on any page: a pop-up explains it, Left/Right turn its pages, release closes it. Hold Shift + Note (Phrase commands) and Shift + Instr params (Table commands): cheat sheets until you let go.
13. Rec + Play on the Phrase page: the note you play should land on the step you heard it on. If it is still early or late by a step, tell me which and by how much.
14. Master key (linked): an A over F1 and a B over F8, no yellow frame; hold either and the F key dock rises, release and it drops.
15. New in 0.4.0, saving: SAVE SONG on A, then on B; the card now has `GB/Saves/A.srm` and `B.srm` (128 KB each). Change the song, SAVE under a new NAME: LOAD SONG lists both. Same name replaces. Shift + Delete, then Insert, erases a listed song. Loose `.lsdsng` files in `GB/Songs` show with a `+`.
16. EXPORT LSDJ: `GB/Export/PTSDJ_A.srm` / `PTSDJ_B.srm` appear. Copy `PTSDJ_A.srm` next to `PTSDJ_A.gb`, start LSDJ: the file manager (Project > LOAD/SAVE) should list the songs; report anything odd (a missing song, garbled names, a song that will not load).
17. Power-on chime: a recording of the supplied WAV now. Tell me if it still sounds short or different.
18. Help key and F8 pop-ups: text is left aligned, names in bold, a blank line between entries; more pages than before.
19. New in 0.4.1: hold F8 on a page with a long explanation; a tab with `<` and `>` appears at the lower left, over F1 and F2. F1 turns back, F2 forward, Left/Right still work.
21. New in 0.4.2: the song list is ` -TITLE` (a bold LOAD SONG title, a blank row under the hint). With kit files in `GB/Kits`, EXPORT LSDJ ends with `EXPORT DONE + ROM` and writes `GB/Export/LSDJ_KITS.gb` (1 MB). Run that ROM with `PTSDJ_A.srm` renamed to match: GUESSWHO's hi-hat should sound like it does on the Tracker. Report if the ROM does not start. Kit slots 13-17 are program code in the stock ROM and are never replaced (status `KIT nn: USE 1A-37`): move such a kit to slot 1A-37.
22. New in 0.5.0, kits: put two or three WAV files in `GB/Samples`. Sample Loader: pick one, Insert (the Sample Editor opens), turn the jog wheel on END to trim, ADD TO KIT. Sample Playback: the kit lists it; Play or a pad hears it. Make a KIT instrument on the Instr page (type KIT, KIT 1 = 1A) and play note 1 from a phrase. Report how the samples sound against the WAV (too noisy? too quiet? clipped?).
23. EXPORT LSDJ now also writes `GB/Export/PTSDJ_A.gb` / `PTSDJ_B.gb`; run one with the matching `.srm` renamed; the kit should sound the same as on the Tracker.
24. Instrument library: Shift + the Instr key (it is not a row on the Instr page). Play on the kit page and the Sample Loader now sounds the whole sample, not one blip. On the kit page Insert on a sample of a ROM kit opens it in the Sample Editor.
25. Firmware loader: Config key (Project page), hold Shift: ? over F8 turns into FIRMWARE; press F8: the window lists the images in /Firmware. Insert twice flashes: try it with the same image first. Delete backs out.
26. New in 0.6.0: Play on the Chain page plays only that chain on the cursor track and loops; Play again stops; Shift + Play plays the song. Same on the Phrase page. On the Table page Play sounds a note with the instrument using that table.
27. NEW SONG: Load Song list, first entry (and the NEW SONG row on the Project page): name it, the song empties. Quit and restart: each console opens the song it saved last. The Project page's bottom line shows only while Shift is held.
28. Sample Loader: Insert adds a WAV to kit 1A and a check mark appears; Delete removes it. Sample Editor: SAMPLES row + jog wheel steps through the kit; REPLACE SAMPLE asks before it replaces. Kicks should sound smoother than before; tell me if they are still harsh.
29. Copy `presets/instruments` (or the zip) to `GB/Instruments`; the library (Shift + Instr) lists them, Left/Right turn a page.
30. Library (Shift + Instr): no `._` files listed. Play previews the highlighted sound; the pads play it; Delete leaves and nothing in the song changed; Insert puts it in.
31. Output level: the same song should be clearly louder than before. Tell me if anything distorts on loud passages.
32. The noise hi-hat with the K command plus two pulse sounds and a kit: no chugging or slow-down any more. If it still chugs, tell me what the Project page's technical line says (hold Shift): `P` is the worst callback in thousands of cycles.
33. EverDrive: `PTSDJ_A.gb` must pass the cartridge test and boot like the original ROM. If it does not, send me what the screen says; the ROM differs from the stock one only in the kit banks and header bytes 0x14E-0x14F.
34. Kits (0.7.0): the kit numbers now follow LSDJ's own bank rule (see README), so a kit made in slot 1A really plays as KIT 1A in the exported PTSDJ_A.gb. Make a kit, export, put `PTSDJ_A.gb` and `PTSDJ_A.srm` on the cart and play a song with that kit.
35. Layering: on a KIT sound set KIT 2 on the Instr page; in the phrase, Insert + Up/Down adds a KIT 2 sample to a step (the note column shows `KK1+SN2`).
36. Recorder (0.8.0, test only after 0.7.0 checks out): Sample Recorder key, INPUT LINE with a cable from a phone or player, TRIGGER LOW, Insert, play the sound: the meter should move, recording should start with the sound, Insert stops and the Sample Editor opens with `REC`. Then try MIC LOW and MIC HIGH. Report: no meter movement, hum, very low or clipped levels, or a freeze when the page opens.
37. Monitor and delete (0.8.1): on the Sample Recorder page you should hear the input through the Tracker while MONITOR is ON (turn it OFF with a mic to avoid squeal). In the Sample Editor, DELETE THIS SAMPLE drops a fresh recording; on a kit sample, DELETE SAMPLE n FROM KIT asks, then removes it and the kit shows the space back.
38. Layer level (0.8.6): add two sounds from different kits with LEVEL 100% and layer them in a phrase (heavy crackle is expected, real LSDJ adds the samples and clips them the same way); re-add both with LEVEL 50% and the layered note should be clean. Sample times on the Kit and Editor pages should show numbers.
39. Layering fix (0.8.7): export again (the song's old kit instruments are repaired on export) and layer two stock kits, for example 606 and Linn: it should sound clean like the original LSDJ ROM.
40. Peak light (0.8.8): Sample Editor, press Play on a loud sound: the red light in the frame flickers where the sound peaks; at LEVEL 25% it should stay dark. BKSP on a Groove step clears it to 00.
41. Demo songs (1.0.1): with a card that has no `GB/Saves/A.srm` or `B.srm`, and no kit files and no `GB/LSDJ.GB`, both consoles should open with DEMO_A and DEMO_B (Project page shows the names, SYNC MASTER on A and SLAVE on B, tempo 170). Press Play on either console: both start, a drum and bass piece in A minor with the breaks, lead and hats on A and the bass, pads and risers on B, the drums coming from the two Amen kits built into the firmware. Compare it with `build/demo/DEMO_A+B.wav` (made with `make demo`): same notes and the same loop. The break (bars 33 to 40, about 0:45) has the pads and the bass and, from 0:49, the long lead. Project > LOAD SONG on each console lists `*DEMO_A` / `*DEMO_B`; Shift + BKSP on it says CAN'T ERASE. Then EXPORT LSDJ and play the pair on two real Game Boys with a link cable (the two kits are in kit slots 0x31 and 0x32, KIT 32 and 33; `PTSDJ_A.gb` has them in banks 62 and 63, so the drums play there as on the Tracker; this needs `GB/LSDJ.GB` on the card).
42. Instrument pages (1.0.0): the rows and values are the LSDJ ROM's. Left / Right on a row pick one of its values (ENV. has three, TABLE has two, VOLUME has two). On a WAVE sound set PLAY to ONCE or LOOP: the WAVE row becomes SYNTH and picks a synth 0 to F, SPEED and LENGTH step through its 16 waves. On a KIT sound try OFFSET, LEN, LOOP and SPEED 0.5X (it plays an octave lower and twice as long). On any sound TABLE STEP should move the table one row per note without changing the envelope. In a phrase, A+Right stops at the top note and an octave step near the top or bottom does nothing. Export a song with a wave instrument on synth 2 and check on a real Game Boy that it plays synth 2.
43. Demo songs, K (1.0.1): play the demo pair through the loop point and into the second intro: the lead, the pads and the bass must not ring on through the quiet bars (the end notes carry a K command).
44. Kit numbers (1.0.0): the screen now counts kits from 01 like the LSDJ ROM, so the kit older items call 1A is shown as 1B (your own kits are shown 16 to 33, the ROM's 01 to 15; kit files keep their old names). Make a kit, set an instrument's KIT 1 to it, export, and play it on a real Game Boy: the instrument page there should show the same number as the Tracker did, and the same kit name beside it.
45. Built-in kits (1.0.1): with the demo loaded, the Kit page of an instrument on A's wave channel shows KIT 32 and 33 with samples (the kicks and snares). Put your own `32_something.kit` in `GB/Kits`: after a restart the demo's drums become that kit's. Take it out again and they come back.
46. Player fixes (1.0.1): a table with `H` on its own row now runs on and wraps instead of holding (hold a row by hopping to the one before it); `R` retriggers at once; a wave bass with V or P is no longer too steady on low notes (an instrument with byte 5 bit 6, the kick drums, is unchanged). Play a song of yours with wave bass vibrato and kicks and tell me if any of them sounds different from before.
20. Back to stock: Config > Firmware update, or the `ot_restore.txt` route, or the Polyend tool.
47. Master volume and loudness (1.0.3): hold Master (more than 0.3 s) or turn the jog wheel while it is down: the battery light turns into a column of squares (muted green at the bottom, through yellow, to red at the top) and the squares light up brightly as far as the music reaches; the number under BATTERY reads 0 DB at the top and goes down by 1.5 DB a step, MUTE at the bottom. The sound follows the knob at once, with no clicks. Release: the light is red (playing) or dark red again and the screen is on the same page, and in the same view, as before the hold. A quick tap on Master (with SYNC on) still switches between one console and both side by side; in the side by side view a hold shows the bar under DOT MATRIX WITH STEREO SOUND. F2 / F7 + jog still set the consoles' own levels. Turn it down, power off and on: it comes back at that level (it is in `GB/MASTER.CFG`).
48. Output loudness (1.0.3): the output is now 2.8 times the chips' own level (it was 1.6) with a limiter instead of the old soft knee. At master 0 DB, compare the demo with your other gear and with 1.0.1: it should be clearly louder (about 5 dB) with no crackle or breakup on the kicks and the bass; on a loud passage the kicks should sound a little shorter or flatter, not distorted. If your headphones are still too quiet, the headphone amplifier (fixed at 0.7, about -7 dB) can be raised separately: tell me.
49. Master Mix page (1.0.3): press Shift + Master (Shift down, then Master): a Game Boy style page "MASTER MIX" opens in the bezel (green screen, black frame, like the other pages) with LIMITER > MASTER VOLUME under the title and five rows: LIMITER ON/OFF, DRIVE, CEILING, RELEASE, MASTER VOLUME. Holding Shift + Master does not show the battery-light meter or change the master volume. Up / Down move the highlight, the jog wheel (or Left / Right) changes the value, the music keeps playing and follows each change without clicks. Check: LIMITER OFF is quieter and the OUTPUT bar stays well below the top; DRIVE +14 DB with the demo makes the REDUCTION bar move on every kick; CEILING -6 DB keeps the OUTPUT bar under that; RELEASE 25 MS vs 500 MS changes how quickly the sound recovers after a kick. Hold F8: the help pop-up for the page (F1 / F2 turn its pages, letting go brings the page back). Master closes the page and the screen is exactly where it was; so does any page key (Song, Pattern, Note, Instr, Fx1, Fx2, Config, File, Performance, Help, the sample keys), and you land on that page. Power off and on: the settings are back. Export a WAV from the Project page and listen: it sounds like the speakers did, and with MASTER VOLUME at -6 DB the file is half as loud. The exported `.srm` / `.lsdsng` / `.gb` songs are the same whatever the page says.
